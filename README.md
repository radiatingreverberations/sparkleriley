# SparkleRiley

A fan-made short series about Riley, 24, known online as SparkleRiley. She is losing an argument with League of Legends matchmaking when her monitor starts to hum.

Made with [Lumibelle](https://lumibelle.ai), a personal video studio for growing an idea into a film. Each episode folder is a complete Lumibelle project: the screenplay, characters, environments and props with their reference images and reels, shots with prompts and takes, and the final cut.

## Open an episode in Lumibelle

1. Install and run [Lumibelle](https://github.com/radiatingreverberations/lumibelle).
2. Clone this repository.
3. In Lumibelle, choose **Your projects → Open project folder…** and select an episode folder, such as `e01`.

The project is edited in place. See [Getting started](https://lumibelle.ai/manual/getting-started/) for more about Lumibelle.

Browsing, editing the script and assets, and re-cutting work without any AI setup. Generating new images, reels or takes needs your own providers and models. Model files, LoRA weights and credentials are not included; the project records the settings each take was made with.

To keep the download small, the project was compacted: the lossless frame archives of takes and reference reels were removed. Takes, reels, saved keyframes and the cut are unaffected, and new frames are decoded from the saved videos.
